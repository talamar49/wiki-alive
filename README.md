# WikiAlive

Wikipedia is knowledge. WikiAlive turns a Wikipedia article into an interactive learning experience.

## Features

- Paste a Wikipedia URL or article title
- Fetches article content through the official Wikipedia API
- Story mode: turns the article into four readable chapters
- Timeline: extracts dated events from the article
- Quiz: creates quick interactive questions from the page
- Cards: breaks the article into digestible concept cards
- Hebrew and English article support
- Attribution links back to Wikipedia / CC BY-SA

## Development

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Notes

This is an MVP. The next strong upgrade is adding an AI backend that can generate richer stories, debates, maps, and teacher/student modes.
